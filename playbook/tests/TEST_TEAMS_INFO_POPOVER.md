# test_teams_info_popover.py

> **Add tests here when:** changing the Teams (i) info popover or its explanation text.

- **Kind:** browser (Playwright). Launches its own browser instead of using a `page` fixture.
- **Needs:** Chromium; the test skips without it.
- **Covers:** the (i) button exists and a click opens a popup showing the expected copy.
- **Not here:** other popovers → `TEST_INSTALL_LINKS.md`.
- **Known gaps:** none recorded.
